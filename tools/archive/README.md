# Archived Development Scripts

This directory preserves one-off scripts used during earlier HTML extraction, module generation/splitting, gameplay patching, migration, and browser/debug experiments.

These files are **not production source**, are not part of the Android build, and may contain stale paths or destructive direct replacements. Do not run them against `app/src/main/assets/` without reviewing and deliberately adapting them for a separately scoped task. They remain in version control for historical investigation only.
